# Audit critique de la chaîne de publication automatique

Date : 6 octobre 2026. Périmètre : `scripts/stories-auto.cjs`, `publier-stories.cjs`, `titres-propres.cjs`, `dossiers.cjs`, `illustrations.js`, `js/stories*.js`, `data/stories-config.json`, les données réelles (`data/actualites.json`, `instagram-file.json`, `instagram-publiees.json`), les images de `instagram/auto`, `modeles` et `publications` (24 images regardées). Au moment de l'audit, aucun script de production n'avait été modifié ; l'état des corrections suit.
Ce document n'est pas un avis juridique : les points de droit sont des risques à faire valider par un juriste.

**Tests** : `tests/audit-publications.test.mjs`. Les tests ordinaires verrouillent ce qui marche ; les tests `todo` (identifiants J-xx et A-xx ci-dessous) échouent aujourd'hui et démontrent chaque défaut sans casser `lancer-tous.mjs`. Quand un défaut est corrigé, l'option `todo` est retirée ; les `todo` restants sont des défauts acceptés (voir ci-dessous).

## État des corrections (branche `claude/corrections-audit`)

Les constats ci-dessous (§ 1 à 3) décrivent l'état AVANT correction. Statut après correction : **corrigé** (test ordinaire dans `tests/audit-publications.test.mjs`, `tests/liste-prudente.test.mjs`, `tests/publier-stories.test.mjs`), **accepté** (le test reste `todo`, avec la raison), **non traité** (hors périmètre de cette série de corrections).

**AVERTISSEMENT (J-23), contenus déjà publiés hors chaîne : à retirer à la main sur Instagram par le propriétaire du compte.** Leur texte viole la liste prudente : `bardella-0210` (« écrits antisémites attribués à Jordan Bardella par Mediapart », portrait et nom : imputation, même attribuée, donc risque de diffamation ; avis d'un juriste conseillé), `jour-0310` (violences sexuelles, plainte, enquête visant une personne nommée), `lyceens-0310` et `lyceens-0410` (violences urbaines, interpellations, mineurs), `post-primaire-0510` (reproche attribué à une personne nommée). Le registre `data/instagram-publiees.json` n'a **pas** été modifié (trace d'historique, anti-doublon). Leurs identifiants sont dans `data/instagram-retires.json` : le publieur ne les republie jamais, ni le publieur ni les stories n'en reprennent le texte (détection de sujets proches), et leurs images hors convention ont été supprimées du site (`instagram/auto/*.jpg`). Les anciennes versions restent dans l'historique Git : une purge d'historique n'a pas été faite. Aucune API ne permet de supprimer une story : la story et les posts éventuels doivent être retirés dans l'application Instagram.
